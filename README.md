# HDR-Plus
[HDR+](https://modrinth.com/modpack/hdr-plus) is a Vanilla+ modpack that brings HDR output to Minecraft using [rrtt217's HDR mod](https://modrinth.com/mod/rrtt217-s-hdr-mod)

[HDR+](https://modrinth.com/modpack/hdr-plus) is a Minecraft Modpack currently supported for version 26.2 on Fabric.

### IMPORTANT

This modpack does *NOT* come with the shaderpacks needed to fully experience this pack.

See [HDR Shaderpacks](https://github.com/rrtt217/Minecraft-HDR-Mod/wiki/HDR-Shaderpacks) for shaders compatible with HDR Mod.
Currently, these shaders are supported with the HDR mod:

    Bliss
    Complimentary - Unbound/Reimagined
    Photon
    ARTShade
    IterationRP
    Revelation
